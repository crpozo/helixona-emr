Orders

Eligibility
domain configuration		 Requested → Received → Failed System requests; Marie retries 3 attempts, 8 seconds apart, then holds and pages Marie “Eligibility check failed. Retry now, or call the payer to verify by phone.”
Readiness
domain configuration		 Calculated → Physician review → Approved | Overridden System calculates; physician or extender approves or overrides with a reason Any missing input fails closed to Physician review “Readiness needs a physician to review it before this infusion can be booked.”
